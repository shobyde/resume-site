boaz · v0.7.8 · free, MIT, open source

An assistant with no model.
Nothing to hide.

Boaz is a free, open-source assistant that answers from your app's own routes, facts and rules, calls them when a question needs live state, and shows the facts behind every sentence. No LLM, no API key, no download.

The trade most assistants make

A model in the tab costs a download, a GPU, and the truth.

Shipping an assistant usually means shipping weights: hundreds of megabytes, a WebGPU requirement, and an answer nobody can check. On a phone with metered data, or a work laptop with the CDN blocked, the assistant is a spinner.

Boaz takes the other position. The app publishes what it can do and what it knows. The library retrieves, joins and composes. When the facts run out, it reads the page it is standing on. Every reply can be traced to the rows that produced it.

Hosted modelper token, per call

  • A key to provision and a bill for every conversation
  • Page text leaves the origin for someone else's server
  • Nothing in the reply can be checked against a source
  • Blocked outright on plenty of work networks

Model in the tabWebLLM, Prompt API

  • Free at the API, but hundreds of megabytes to fetch
  • Needs a capable GPU and a browser that ships the API
  • Metered data or a blocked CDN leaves a spinner
  • Still no provenance: plausible text is the product

Boazthis page

  • Free and MIT: one package, no per-call billing
  • No key, no account, no network call during a turn
  • Each sentence carries the rows and the rule behind it
  • When the data is missing it says so, by name

The honest limit. This is not a general-purpose chatbot. It cannot write an essay about a topic nobody declared, and it should not pretend to. It answers what the app actually knows, which on most pages is most of what a visitor asks.

Anatomy

One turn, five steps, no inference server.

Capabilities are declared beside the feature that owns them

A build step extracts them with the TypeScript AST into one manifest: routes, actions, queries, and prose knowledge.

The question is ranked against that manifest

BM25 over titles, keywords and descriptions. Twenty-two capabilities take about three microseconds, which is why retrieval is not the thing the visitor waits for.

If the answer needs live data, the engine calls the app

A rule declares the tools it needs. The runtime runs one, hands back the structured result, and the engine turns it into facts for this turn.

Rules join the question to the facts

A small Datalog subset: joins, scoped assumptions, a depth cap. projects_using(?P) :- uses(?P, ?T), asked(?T).

The sentence is composed, then streamed with its trace

The app writes the words, the library streams them, and the steps it took stay on screen above the answer.

src/agent/assistant.jsthe rule
// The app's half: which tool, and how a solution becomes a sentence.
{
  id: 'projects.using',
  title: 'Which projects use a technology',
  keywords: ['which projects use', 'built with'],
  goal: 'projects_using(?P)',
  steps: [{
    capabilityId: 'projects.list',
    toFacts: (result) => result.projects.flatMap((p) => [
      fact('project', slug(p.title), p.title),
      ...p.stack.map((t) => fact('uses', slug(p.title), t)),
    ]),
  }],
  compose: ({ solutions }) => `${solutions.length} projects use it.`,
}

A2UI

The interface assembles itself, and the page keeps its design system.

Honesty

What it will not do.

ParaphraseAnswers are composed from declared text and data. It will not invent a sentence about something nobody wrote down.
World knowledgeAsk about the weather and it has nothing. The knowledge base is the app's, not the internet's.
Open-ended opinions"Why should I hire him" gets facts and a deflection, because a judgement is yours to make.
Rules you did not writeCoverage is the work. Every new question shape is a rule, a fact, or a scan, and that is the point.

Questions

Free, in the browser, and no key to manage.

Is it really free?

Yes. MIT licensed, no per-call billing, no hosted tier to upgrade into, no account. The whole cost is the JavaScript already in your bundle.

Do I need an API key or a model download?

Neither. No model runs in the loop, so there is nothing to download and nothing to authenticate. A turn makes no network request; the page's own data and DOM are the source.

How is this different from a free in-browser LLM?

A model in the tab still guesses. Boaz retrieves a capability or joins a rule, so the sentence is derived from rows the app declared and it can show them. The trade is coverage: it answers what was declared, and says out loud when the answer is not there.

Can it replace a chat widget on a marketing site?

For navigation, "what does this section do", pricing, docs lookup and "show me the form", yes: those are declarations plus a few rules. For open-ended conversation about anything, no, and the page says so when it cannot answer.

What does it cost to run in production?

Nothing per turn. The work happens in the visitor's browser against a 7.7 kB manifest, so an answer costs about what rendering a list costs.

Where is it used today?

This site's assistant runs on it: 22 declared capabilities, rules over the project and post data, and a page scan for contact details. Source and release tarball are on GitHub.

The name

Boaz kept the record.

In Ruth 4, Boaz settles a transaction at the city gate, in front of ten elders, where it can be witnessed: "you are witnesses this day." In Ruth 2:11, asked why Ruth had found favor, he answers from what had been reported to him, not from what he could guess.

That is the contract this library keeps, in both directions. A change happens where it can be seen: the id must exist in the manifest, the arguments are validated before a handler runs, and a mutating action waits for a confirmation. An answer comes from the record: facts the app declared, rules it wrote, or the page it is standing on, with the steps shown above the sentence.

Formerly client-agent. The package carried that name through 0.6.10. 0.7.0 renames the package, the CLI, the virtual module and the shipped skill to boaz; the entry points and the behaviour are unchanged.

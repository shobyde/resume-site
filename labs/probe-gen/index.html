Turn a manifest into a probe file

A capability manifest already lists two things a test needs: what each capability does, and the phrases a visitor uses to ask for it. This page turns those into questions, then names the ones it will not decide for you.

The generator runs in this tab, on the JSON below. Nothing is sent anywhere. Edit the manifest in the box and press generate to try your own.
